# Ajustes

## Abra os ajustes

Clique no botão de engrenagem do rodapé do painel. A tela de ajustes substitui o conteúdo do painel. O rodapé continua.

Para fechar os ajustes, faça uma destas coisas:

- Clique de novo no botão de engrenagem.
- Clique no botão de voltar **‹ Ajustes**, no alto.
- Clique em uma aba, **Prioridades** ou **Notas**.

## As quatro linhas

A tela tem quatro linhas, nesta ordem. O texto de cada linha está em espanhol, como no app.

| Linha | Texto embaixo do título | Valor inicial |
|---|---|---|
| `Abrir al iniciar sesión` | `Abre Daily ZGT cuando inicias sesión en tu Mac.` | desligado |
| `Máximo 5 prioridades abiertas en Hoy` | `Con 5 abiertas en Hoy, no puedes añadir ni mover otra a Hoy.` | desligado |
| `Siguiente prioridad en la barra de menús` | `Muestra junto al ícono el título de la primera prioridad abierta de Hoy.` | ligado |
| `Atajo global` | `Abre la ventana de captura desde cualquier app.` | `⌃⌥⌘P` |

As três primeiras linhas têm um interruptor. A quarta linha tem um campo para o atalho.

### Abrir al iniciar sesión

O interruptor faz o app iniciar quando você abre a sessão no seu Mac. Ele usa a API do sistema `SMAppService.mainApp`, sem app auxiliar.

Em alguns casos o macOS precisa da sua aprovação. O interruptor continua ligado, e a linha mostra `Falta tu aprobación en Ajustes del Sistema.` com o link `Abrir ajustes`. O link abre a página de itens de início nos Ajustes do Sistema. Aprove ali o Daily ZGT. A linha se atualiza quando você volta ao app.

Se o macOS recusar a mudança, a linha mostra `macOS no aceptó el cambio.`

O app não guarda este ajuste no banco de dados. Quem o guarda é o macOS.

### Máximo 5 prioridades abiertas en Hoy

Quando o interruptor está ligado e Hoy tem 5 prioridades abertas, o app não adiciona nem move outra prioridade para Hoy. Ele mostra `Hoy ya tiene 5 prioridades abiertas.` **Deshacer**, **Regresar** e a cópia diária nunca são bloqueados. Veja [Prioridades](/guide/use/priorities).

O app guarda este ajuste na tabela `app_state`, com a chave `today_limit`.

### Siguiente prioridad en la barra de menús

Quando o interruptor está ligado, a barra de menus mostra o título da primeira prioridade aberta de Hoy ao lado da quantidade. O título é cortado em 24 caracteres. Quando o interruptor está desligado, a barra de menus mostra só o ícone e a quantidade.

O app guarda este ajuste na tabela `app_state`, com a chave `menu_bar_title`.

### Atajo global

O campo mostra o atalho que abre a [janela de captura](/guide/use/capture). O valor inicial é `⌃⌥⌘P` (Control, Option, Command e P).

- Para mudar o atalho, clique no campo. O campo pede um novo atalho. Pressione as teclas novas. O atalho precisa da tecla Control, Option ou Command, ou de uma tecla de função. Se o macOS ou o menu do app já usarem essas teclas, o campo pode mostrar um alerta.
- Para apagar o atalho, clique no botão de apagar do campo, ou pressione Delete enquanto o campo grava. O texto de apoio diz então `Sin atajo: la ventana de captura no se abre desde otras apps.`
- Para parar de gravar sem mudanças, pressione Escape.

O app guarda este ajuste nas preferências do app, não no banco de dados. A chave é `KeyboardShortcuts_captureWindow` no domínio `com.giancarlosisasi.dailyzgt`. Leia-a com este comando:

```bash
defaults read com.giancarlosisasi.dailyzgt KeyboardShortcuts_captureWindow
```

## Movimento

O app não tem um ajuste de movimento. Ele segue o ajuste **Reduzir movimento** do macOS. Quando esse ajuste está ativo, o app não mostra movimento. Os movimentos são: a aparição do painel, a linha que desliza ao marcar uma prioridade como concluída, o giro da seta, a entrada da tela de detalhe, a volta da lista e a marca que se desenha quando uma lista está vazia.

## Onde o app guarda o estado

| O quê | Onde |
|---|---|
| Aba aberta, lista aberta, estado de **Hechas** | Tabela `app_state`: `open_tab`, `open_scope`, `done_open` |
| O limite de 5 e o título na barra de menus | Tabela `app_state`: `today_limit`, `menu_bar_title` |
| Iniciar ao abrir a sessão | macOS |
| Atalho global | Preferências do app |

Veja [Banco de dados](/guide/data/database).
