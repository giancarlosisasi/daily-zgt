# Janela de captura

Adicione uma prioridade de qualquer app, sem abrir o painel. Pressione o atalho, digite e pressione Enter.

| Sistema | Atalho |
|---|---|
| Windows | Ctrl+Alt+Shift+P |
| macOS | Control+Option+Command+P |

<img src="/shots/pt/capture.png" alt="A janela de captura pequena com o título Nova prioridade, o texto Responder o e-mail da Marta no campo e a dica Enter adiciona. Escape fecha." width="360" />

- **Enter** adiciona a prioridade em **Hoje**, com nível **Média** e sem prazo.
- **Escape** fecha a janela sem mudanças.

Para definir nível ou prazo, abra a prioridade no painel depois. Para usar outras teclas, mude o atalho nos [Ajustes](/guide/features/settings).
