# Notas

A aba **Notas** tem uma nota para hoje e outra para a semana. Clique em **Hoje** ou **Semana** para trocar.

<img src="/shots/pt/notes.png" alt="A aba Notas com Notas de hoje e o texto Ligar para a Marta antes das 17h. Abaixo do campo, a dica Salva ao digitar." width="360" />

O app salva enquanto você digita. Não há botão de salvar.

Cada dia novo começa com uma nota vazia, e cada semana nova também. O painel mostra só a nota do dia e da semana atuais.

Cada prioridade também tem a própria nota, nos [detalhes](/guide/features/priorities).
