# Perguntas frequentes

## Não vejo o ícone

No Windows, clique na seta para cima perto do relógio, **Mostrar ícones ocultos**. Arraste o ícone do Daily ZGT para a barra de tarefas para deixá-lo sempre à vista.

No macOS, uma barra de menus cheia pode esconder ícones, também atrás do notch da tela. Feche outro app da barra de menus, ou desligue o título da próxima prioridade nos [Ajustes](/guide/features/settings) para ocupar menos espaço.

## Os alertas não aparecem

Confira se as notificações do Daily ZGT estão ativadas e se o Não incomodar (Windows) ou o Foco (macOS) está desligado. Depois clique em **Testar alerta** na parte de baixo do painel. Veja [Alertas](/guide/features/alerts).

## O atalho não funciona

O Daily ZGT precisa estar aberto para o atalho funcionar. Outro app também pode usar as mesmas teclas. Abra os [Ajustes](/guide/features/settings), clique em **Atalho global** e pressione outras teclas.

## O Windows diz "O Windows protegeu o computador"

O instalador não tem assinatura de código, então o SmartScreen avisa você. Clique em **Mais informações** e depois em **Executar assim mesmo**. Veja [Instalar](/guide/getting-started/download).

## Como levo meus dados para outro computador?

Instale o Daily ZGT no computador novo. Feche o app nos dois computadores. Depois copie a pasta `DailyZGT` do computador antigo para o mesmo lugar no novo. Veja [Privacidade e seus dados](/guide/help/privacy).

## É gratuito?

Sim. O Daily ZGT é gratuito e de código aberto, com a licença MIT. Não há conta nem nada para pagar.
