# Ventana de captura

Agrega una prioridad desde cualquier app, sin abrir el panel. Presiona el atajo, escribe y presiona Enter.

| Sistema | Atajo |
|---|---|
| Windows | Ctrl+Alt+Shift+P |
| macOS | Control+Option+Command+P |

<img src="/shots/es/capture.png" alt="La ventana de captura pequeña con el título Nueva prioridad, el texto Responder el correo de Marta en su campo y el aviso Enter agrega. Escape cierra." width="360" />

- **Enter** agrega la prioridad a **Hoy**, con nivel **Media** y sin hora límite.
- **Escape** cierra la ventana sin cambios.

Para ponerle nivel u hora límite, abre la prioridad en el panel después. Para usar otras teclas, cambia el atajo en [Ajustes](/guide/features/settings).
