# Notas

La pestaña **Notas** tiene una nota para hoy y otra para la semana. Haz clic en **Hoy** o **Semana** para cambiar.

<img src="/shots/es/notes.png" alt="La pestaña Notas con Notas de hoy y el texto Llamar a Marta antes de las 5. Bajo el campo, el aviso Se guarda al escribir." width="360" />

La app guarda mientras escribes. No hay botón de guardar.

Cada día nuevo empieza con una nota vacía, y cada semana nueva también. El panel muestra solo la nota del día y de la semana actuales.

Cada prioridad tiene además su propia nota, en su [detalle](/guide/features/priorities).
