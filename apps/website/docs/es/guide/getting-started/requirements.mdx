# Requisitos

Necesitas tres cosas en tu Mac.

| Herramienta | Versión | Cómo obtenerla |
|---|---|---|
| macOS | 14 o superior | La app usa `@Observable`, que necesita macOS 14. |
| Xcode | 26 | Instálalo desde la App Store o desde [developer.apple.com/xcode](https://developer.apple.com/xcode/). |
| XcodeGen | cualquier versión actual | `brew install xcodegen` |

El plan se escribió en un Mac con macOS 26.1, Xcode 26.1.1 y Swift 6.2.1.

## Homebrew

El comando `brew install xcodegen` necesita Homebrew. Instala Homebrew desde [brew.sh](https://brew.sh) si el comando `brew` no existe.

## XcodeGen

XcodeGen lee el archivo `apps/macos/project.yml` y escribe el proyecto de Xcode. El proyecto de Xcode no está en git. Lo creas en tu Mac con `xcodegen generate`.

## Red

La primera compilación descarga los paquetes de Swift que lista `apps/macos/project.yml`. La lista tiene dos paquetes: GRDB, la biblioteca de SQLite, y KeyboardShortcuts, que registra y escucha el atajo global.

## Firma

El proyecto firma la app con la identidad ad hoc (`CODE_SIGN_IDENTITY: "-"`). No necesitas una cuenta de Apple Developer.

## Herramientas opcionales

- `sqlite3` lee la base de datos. macOS ya lo incluye. Mira [Base de datos](/guide/data/database).
- Una clave de API de Anthropic solo sirve para la revisión planeada para v2. Mira [Revisión con Claude y clave de API](/guide/claude/api-key).
