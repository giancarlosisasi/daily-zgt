# Privacy and your data

Daily ZGT keeps all your priorities and notes in one file on your computer.

| System | File |
|---|---|
| Windows | `%LOCALAPPDATA%\DailyZGT\daily-zgt.sqlite` |
| macOS | `~/Library/Application Support/DailyZGT/daily-zgt.sqlite` |

- There is no account and no server.
- The app has no analytics and does not use the internet. Nothing leaves your computer.
- When you uninstall the app, the file stays. Delete its folder if you want your data gone.

## Back up

1. Quit Daily ZGT. Click **Quit** at the bottom of the panel.
2. Open the `DailyZGT` folder. On Windows, paste `%LOCALAPPDATA%\DailyZGT` in the address bar of File Explorer. On macOS, in Finder, choose Go > Go to Folder and paste `~/Library/Application Support/DailyZGT`.
3. Copy the folder to a safe place.

To restore, quit the app and copy the folder back.
