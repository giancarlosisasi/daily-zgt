# Capture window

Add a priority from any app, without opening the panel. Press the shortcut, type, press Enter.

| System | Shortcut |
|---|---|
| Windows | Ctrl+Alt+Shift+P |
| macOS | Control+Option+Command+P |

<img src="/shots/en/capture.png" alt="The small capture window titled New priority, with the text Reply to Marta's email in its field and the hint Enter adds. Escape closes." width="360" />

- **Enter** adds the priority to **Today**, with level **Medium** and no due time.
- **Escape** closes the window with no change.

To add a level or a due time, open the priority in the panel later. To use other keys, change the shortcut in [Settings](/guide/features/settings).
