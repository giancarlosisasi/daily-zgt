# Notes

The **Notes** tab holds one note for today and one for the week. Click **Today** or **Week** to switch.

<img src="/shots/en/notes.png" alt="The Notes tab with Notes for today and the text Call Marta before 5. Under the field, the hint Saved as you type." width="360" />

The app saves as you type. There is no save button.

A new day starts with an empty note, and a new week does too. The panel shows only the note of the current day and week.

Each priority also has its own note, in its [details](/guide/features/priorities).
