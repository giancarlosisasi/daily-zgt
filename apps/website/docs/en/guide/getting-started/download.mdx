# Install

## Windows

You need 64-bit Windows 10 (build 19041 or later) or Windows 11. You do not need admin rights.

<Steps>

### Download the installer

Open the [latest release](https://github.com/giancarlosisasi/daily-zgt/releases/latest) and download `DailyZGT.Windows-win-Setup.exe`.

### Run it

Double-click the file. Daily ZGT installs and opens. Its icon shows in the system tray, and a `Daily ZGT` shortcut shows in the Start menu.

### Get past the SmartScreen warning

The installer has no code signature, so Windows can show "Windows protected your PC". Click **More info**, then **Run anyway**.

</Steps>

**Uninstall.** Open Settings > Apps > Installed apps, find Daily ZGT and choose **Uninstall**. Your data stays on your computer.

**Update.** Uninstall the app, then run the newer installer. Your data stays.

## macOS

There is no download for macOS. You build the app on your Mac from the source code. You need macOS 14 or later, Xcode 26, XcodeGen and `just` (`brew install xcodegen just`).

```bash
git clone https://github.com/giancarlosisasi/daily-zgt.git
cd daily-zgt
just mac-install
open /Applications/DailyZGT.app
```

`just mac-install` builds the app and copies it to your Applications folder. The app has no Dock icon. Click the target icon in the menu bar to open the panel.

To update, quit the app, run `git pull` and `just mac-install` again.

A coding agent such as Claude Code, Cursor or Codex can do the steps above for you. Copy this prompt and paste it into your agent.

- If a step fails, show me the error and explain it before you try something else.
