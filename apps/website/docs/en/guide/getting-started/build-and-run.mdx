# Build and run

There is no App Store build and no download. You build the app from the source folder on your own Mac.

<Steps>

### Clone the repository

```bash
git clone https://github.com/giancarlosisasi/daily-zgt.git
```

The command makes the source folder, named `daily-zgt`.

### Open a terminal in the source folder

```bash
cd daily-zgt
```

### Install the app

```bash
./apps/macos/scripts/install.sh
```

The script generates the Xcode project, builds the Release configuration and copies the app to `/Applications/DailyZGT.app`. If Daily ZGT runs from `/Applications`, quit it first. The script stops while the app runs.

### Start the app

```bash
open /Applications/DailyZGT.app
```

The app has no Dock icon. Look for the target icon in the menu bar. Click it to open the panel.

</Steps>

## Stop the app

The panel has a **Salir** button in its footer. It quits the app.

You can also stop the app from the terminal.

```bash
kill $(pgrep -x DailyZGT)
```

## Run the tests

```bash
cd apps/macos
xcodebuild -project DailyZGT.xcodeproj -scheme DailyZGT -destination 'platform=macOS' -derivedDataPath build test
```

## Update the app

When you change the source, quit the app and run `./apps/macos/scripts/install.sh` again. Then start the app.
