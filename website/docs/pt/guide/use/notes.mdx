# Notas

A aba **Notas** tem um texto para o dia e um texto para a semana.

- A aba de escopo **Hoy** mostra `Notas de hoy`.
- A aba de escopo **Semana** mostra `Notas de la semana`.

O campo de texto tem o texto de ajuda `Escribe una nota`. A indicação embaixo do campo diz `Se guarda al escribir.` O app salva a nota enquanto você digita, 400 ms depois que você para. Ele também salva quando você muda de aba ou quando o painel perde o foco. Não há botão de salvar.

Se o salvamento falhar, a indicação muda para `No se pudo guardar la nota.`

## Cada período tem a sua própria nota

Cada dia guarda a sua própria nota. Cada semana guarda a sua própria nota. `Notas de hoy` sempre mostra a nota do dia local atual. Quando o dia muda, o campo mostra a nota vazia do novo dia. A nota anterior continua no banco de dados.

O app guarda as notas na tabela `note`:

| Coluna | Exemplo |
|---|---|
| `scope` | `day` ou `week` |
| `period` | `2026-10-12` para um dia, `2026-W42` para uma semana |
| `body` | O texto |

O par `scope` e `period` é único, então um dia ou uma semana tem no máximo uma nota.

Se outro programa mudar a nota no banco de dados, o campo mostra o novo texto. O campo não muda enquanto você tem uma edição sem salvar.

Veja [Banco de dados](/guide/data/database) para ler as notas com `sqlite3`.
