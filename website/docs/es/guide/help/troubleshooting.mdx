# Solución de problemas

## El icono no aparece

1. Comprueba que la app esté en ejecución.

```bash
pgrep -x DailyZGT
```

Si el comando no imprime nada, la app no está en ejecución. Inicia la app otra vez. Mira [Compilar y ejecutar](/guide/getting-started/build-and-run).

2. Busca el icono de la mira al lado derecho de la barra de menús. La app no tiene icono en el Dock. Es lo normal.
3. Si la barra de menús está llena, macOS puede ocultar los últimos iconos. En un Mac con notch, los iconos pueden quedar detrás del notch. Cierra otra app de la barra de menús para hacer espacio. También puedes apagar el ajuste `Siguiente prioridad en la barra de menús`. Sin el título, el elemento es más corto. Mira [Ajustes](/guide/use/settings).
4. Si la compilación no terminó, mira [La compilación falla](#build-fails).

## No aparece ninguna alerta \{#no-alert}

1. Mira el botón de campana del pie. Si la campana tiene una raya, o si aparece la línea `Las alertas están desactivadas.`, las alertas de macOS están apagadas para la app. Haz clic en `Abrir ajustes` para abrir los ajustes de notificaciones de macOS. Mira [Alertas](/guide/use/alerts).
2. Haz clic en el botón de campana **Probar alerta** del pie. La alerta de prueba llega 5 segundos después. Si no aparece una alerta de prueba, el problema está en macOS.
3. Abre **Ajustes del Sistema**, después **Notificaciones**, después **Daily ZGT**. Activa **Permitir notificaciones**. Comprueba que el estilo de alerta no sea **Ninguna**. Activa el sonido.
4. La app pide el permiso la primera vez que fijas una fecha límite. Si la app no está en la lista, fija una fecha límite en una prioridad y responde el diálogo.
5. Comprueba que no haya un modo de concentración activo. Un modo de concentración puede silenciar las alertas.
6. Comprueba que la prioridad tenga una fecha límite en el futuro. Una prioridad sin fecha límite no recibe alertas. Una hora límite dentro de menos de 30 minutos recibe solo la alerta a la hora límite.

## El atajo no abre la ventana de captura

1. Comprueba que la app esté en ejecución. El atajo funciona solo mientras la app corre.
2. Abre los ajustes con el botón de engranaje. Mira la fila `Atajo global`. Si el texto dice `Sin atajo: la ventana de captura no se abre desde otras apps.`, el atajo está borrado. Haz clic en el campo y pulsa teclas nuevas.
3. Otra app puede usar las mismas teclas. Haz clic en el campo y pulsa otras teclas.

Mira [Ventana de captura](/guide/use/capture).

## Iniciar al abrir sesión no se queda encendido

1. Abre los ajustes con el botón de engranaje. Si la fila `Abrir al iniciar sesión` muestra `Falta tu aprobación en Ajustes del Sistema.`, haz clic en `Abrir ajustes`. Aprueba Daily ZGT en la página de elementos de inicio de Ajustes del Sistema.
2. Si la fila muestra `macOS no aceptó el cambio.`, apaga el interruptor y enciéndelo otra vez.

## La compilación falla \{#build-fails}

1. Ejecuta `xcodegen generate` otra vez. El proyecto de Xcode no está en git. Puede faltar o estar desactualizado.

```bash
xcodegen generate
```

2. Comprueba que `xcodebuild` use Xcode 26.

```bash
xcodebuild -version
xcode-select -p
```

3. Comprueba tu red. La primera compilación descarga los paquetes de Swift GRDB y KeyboardShortcuts.
4. Borra la carpeta `build/` y compila otra vez. Solo guarda resultados de compilación.

```bash
rm -rf build
xcodegen generate
```

5. Comprueba que tu Mac use macOS 14 o superior.

## El archivo de la base de datos no existe

La app crea el archivo la primera vez que inicia. Inicia la app una vez. Después lista las tablas otra vez. Mira [Base de datos](/guide/data/database).
