# Compilar y ejecutar

No hay versión de App Store ni descarga. Compilas la app desde la carpeta del código fuente, en tu propio Mac.

<Steps>

### Clona el repositorio

```bash
git clone https://github.com/giancarlosisasi/daily-zgt.git
```

El comando crea la carpeta del código fuente, llamada `daily-zgt`.

### Abre una terminal en la carpeta del código fuente

```bash
cd daily-zgt
```

### Instala la app

```bash
./scripts/install.sh
```

El script genera el proyecto de Xcode, compila la configuración Release y copia la app a `/Applications/DailyZGT.app`. Si Daily ZGT está abierta desde `/Applications`, ciérrala antes. El script no continúa mientras la app está abierta.

### Inicia la app

```bash
open /Applications/DailyZGT.app
```

La app no tiene icono en el Dock. Busca el icono de la mira en la barra de menús. Haz clic en él para abrir el panel.

</Steps>

## Detén la app

El pie del panel tiene un botón **Salir**. Cierra la app.

También puedes detener la app desde la terminal.

```bash
kill $(pgrep -x DailyZGT)
```

## Ejecuta las pruebas

```bash
xcodebuild -project DailyZGT.xcodeproj -scheme DailyZGT -destination 'platform=macOS' -derivedDataPath build test
```

## Actualiza la app

Cuando cambias el código, cierra la app y ejecuta `./scripts/install.sh` otra vez. Después inicia la app.
