# Requirements

You need three things on your Mac.

| Tool | Version | How to get it |
|---|---|---|
| macOS | 14 or later | The app uses `@Observable`, which needs macOS 14. |
| Xcode | 26 | Install it from the App Store or from [developer.apple.com/xcode](https://developer.apple.com/xcode/). |
| XcodeGen | any current version | `brew install xcodegen` |

The plan was written on a Mac with macOS 26.1, Xcode 26.1.1 and Swift 6.2.1.

## Homebrew

The command `brew install xcodegen` needs Homebrew. Install Homebrew from [brew.sh](https://brew.sh) if the command `brew` is not found.

## XcodeGen

XcodeGen reads the file `project.yml` and writes the Xcode project. The Xcode project is not in git. You make it on your Mac with `xcodegen generate`.

## Network

The first build downloads the Swift packages that `project.yml` lists. The list has two packages: GRDB, the SQLite library, and KeyboardShortcuts, which records and listens to the global shortcut.

## Signing

The project signs the app with the ad hoc identity (`CODE_SIGN_IDENTITY: "-"`). You need no Apple Developer account.

## Optional tools

- `sqlite3` reads the database. macOS includes it. See [Database](/guide/data/database).
- An Anthropic API key is only for the review that is planned for v2. See [Claude review and the API key](/guide/claude/api-key).
