# Daily repeat

A priority can repeat each day. You do not type it again each morning.

## Set the repeat

1. Open the detail view of the priority. See [Detail and subtasks](/guide/use/detail-and-subtasks).
2. In the row **Repetir**, choose **Cada día**.

The other key is **No**. It is the default.

## When a copy comes

A series is a priority and its copies. The app adds one open copy to Hoy when all three rules are true:

1. The series has no open copy.
2. The priority of the series that you marked done last has **Cada día**.
3. You marked that priority done on a day before today (local time).

So if you mark a daily priority done today, the copy comes tomorrow.

The app checks the rules when it starts, when the day changes, when it becomes the active app, and after each change in the data. The copy goes to Hoy, even if the priority was in Semana.

The copy has:

- The same title, level and note.
- The subtasks of the priority, all open.
- A due time at the same time of day, on today. If that time has passed, the chip shows `Vencida`.
- **Cada día**, so the series goes on.

The copy shows no `De ayer` chip. It starts today.

There are never two open copies of one series.

## What a restore does

**Regresar** and **Deshacer** can bring back a priority that has an open copy.

- If you did not change the open copy, the app deletes the copy. The priority that you restored takes its place.
- If you changed the open copy, the app keeps it. The priority that you restored leaves the series, and its repeat becomes **No**.

A change is any edit of the copy: title, level, due date, note, list, a subtask or a move. The checkbox of a subtask counts as a change.

## What a delete does

If you delete an open priority of a series, the series ends. The app sets **No** on each priority of the series. No new copy comes.

If you delete a done priority, the series goes on.

## Stop the repeat

Do one of these:

- Open the open priority and choose **No** in the row **Repetir**.
- Delete the open priority.

## In the database

The table `priority` has two columns for this:

| Column | Values |
|---|---|
| `repeat_rule` | `none` or `daily` |
| `repeat_series_id` | `null` for a series of one. Each copy holds the `id` of the first priority of its series. |

See [Database](/guide/data/database).
